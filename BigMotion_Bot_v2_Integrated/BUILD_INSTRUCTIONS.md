# 🚀 Building BigMotion Trading Bot Executable

## Quick Start

### Install Dependencies:
```bash
pip install -r requirements.txt
```

### Build Executable:
```bash
pyinstaller BigMotion_Bot.spec
```

### Test:
```bash
cd dist
.\BigMotion_Trading_Bot.exe
```
