# 🚀 BIGMOTION AUTOFX v3 - PRODUCTION BUILD GUIDE
## (Optimized for xgboost + lightgbm - No CatBoost!)

## ✅ WHY NO CATBOOST?

**CatBoost requires:**
- ❌ Microsoft Visual Studio 2022 (3-5 GB download)
- ❌ Long compilation time (10-30 minutes)
- ❌ Complex build environment

**You don't need it because:**
- ✅ xgboost is your primary ML library (best performance)
- ✅ lightgbm is excellent backup (fast, efficient)
- ✅ Your trained model likely uses xgboost primarily
- ✅ Simpler deployment (fewer dependencies)
- ✅ Smaller .exe file (~100-110 MB vs ~120-130 MB)

## 🎯 PRODUCTION SETUP (3 Steps!)

### Step 1: Install Production Requirements

```powershell
cd C:\Users\Administrator\Documents\Project2026\BigMotion_Bot_v3

# Install everything (without catboost)
pip install -r requirements.txt
```

**Or install manually:**
```powershell
pip install MetaTrader5 pandas numpy scikit-learn xgboost lightgbm reportlab matplotlib requests python-telegram-bot cryptography python-dotenv pyinstaller
```

---

### Step 2: Verify ML Libraries

```powershell
# Check what you have
python -c "import xgboost; print('xgboost:', xgboost.__version__)"
python -c "import lightgbm; print('lightgbm:', lightgbm.__version__)"
```

**Expected output:**
```
xgboost: 2.0.3
lightgbm: 4.5.0
```

---

### Step 3: Build!

```powershell
# Use the production .spec file
copy BigMotion_Bot_PRODUCTION.spec BigMotion_Bot.spec

# Clean previous builds
Remove-Item -Path dist,build -Recurse -ErrorAction SilentlyContinue

# Build the .exe
pyinstaller BigMotion_Bot.spec

# Copy your ML model
copy models\trading_model.pkl dist\models\
```

**Expected build output:**
```

Scanning for ML libraries (xgboost + lightgbm)...
  ✅ XGBoost: xgboost.dll (106 MB)
```

## 🐛 TROUBLESHOOTING

### "xgboost.dll not found"

**Check:**
```powershell
cd dist\xgboost\lib
dir xgboost.dll  # Should show 106 MB file
```

**If missing:**
1. Verify xgboost installed: `pip list | findstr xgboost`
2. Rebuild: `pyinstaller BigMotion_Bot.spec`

---

### "ML model not loading"

**Check:**
1. `dist\models\trading_model.pkl` exists?
2. `dist\xgboost\lib\xgboost.dll` exists?
3. What's the exact error in logs?

---

### "Still getting catboost errors"

**Solution:**
```powershell
# Uninstall catboost if partially installed
pip uninstall catboost -y

# Clean build
Remove-Item -Path dist,build -Recurse -Force

# Rebuild
pyinstaller BigMotion_Bot.spec
```
